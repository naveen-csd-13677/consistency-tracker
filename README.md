# Consistency Tracker

A project designed to help track and manage consistency in various applications and processes.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/naveen-csd-13677/consistency-tracker.git
   ```
2. Navigate into the directory:
   ```bash
   cd consistency-tracker
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Set up environment variables as needed and modify `.env` accordingly.
